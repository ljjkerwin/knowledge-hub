# Agentic RAG 问答系统实施方案

## 项目现状分析

### ✅ 已完成（写入管道）
- ChunkingService - Markdown 感知分块（512 token/块）
- EmbeddingService - 向量嵌入（1024 维，兼容 OpenAI/DashScope）
- VectorIndexService - ES kNN 向量索引（kh_chunk）
- SearchIndexService - ES 全文索引（kh_document）
- ExtractionService - LLM 实体关系抽取
- GraphBuildService - Neo4j 知识图谱构建
- PipelineOrchestrator - MQ 异步编排

### ❌ 缺失（查询侧）
- RAG 查询服务（向量检索 + 混合检索）
- 问答生成服务（LLM 生成答案 + 引用溯源）
- 查询 API 接口
- Agent 编排能力
- 多轮对话管理

---

## 技术选型

| 组件 | 选型 | 理由 |
|---|---|---|
| **LLM** | OpenAI 兼容 API | 支持 DeepSeek/Moonshot 等，可配置 base URL |
| **对话存储** | PostgreSQL | 使用 TypeORM，与现有数据统一管理 |
| **检索引擎** | Elasticsearch | 已有 kh_chunk（向量）和 kh_document（全文）索引 |
| **流式响应** | SSE (Server-Sent Events) | NestJS 原生支持，前端实现简单 |
| **权限控制** | 完整权限系统 | 集成用户系统，细粒度访问控制 |

## 阶段 1：基础 RAG 查询

### 目标
实现单轮问答，跑通「用户提问 → 检索 → 生成答案」完整链路。

### 模块结构

```
src/rag/

├── rag.controller.ts          # 查询 API
├── rag.service.ts             # 业务编排（单轮查询）
├── retrieval.service.ts       # 检索服务
├── generation.service.ts      # 答案生成服务
├── dto/
│   ├── query.dto.ts           # 查询请求 DTO
│   └── response.dto.ts        # 查询响应 DTO
```

### 核心服务

#### 1. RetrievalService（检索服务）

```typescript
@Injectable()
export class RetrievalService {
  constructor(
    private readonly es: ElasticsearchService,
    private readonly embeddingService: EmbeddingService,
    private readonly config: ConfigService,
  ) {}

  // 向量检索（kNN）
  async vectorSearch(query: string, options?: SearchOptions): Promise<SearchResult[]>

  // 关键词检索（BM25）
  async keywordSearch(query: string, options?: SearchOptions): Promise<SearchResult[]>

  // 混合检索（向量 + 关键词）
  async hybridSearch(query: string, options?: SearchOptions): Promise<SearchResult[]>
}
```

**检索流程：**
1. 用户 query → EmbeddingService.embed() → queryVector
2. ES kNN 搜索 kh_chunk 索引（cosine similarity）
3. ES BM25 搜索 kh_document 索引（可选）
4. 结果融合（RRF 或加权）
5. 返回 Top-K chunks

**配置项：**
- `RAG_TOP_K`：返回结果数量（默认 5）
- `RAG_SIMILARITY_THRESHOLD`：相似度阈值（默认 0.7）
- `RAG_HYBRID_ALPHA`：混合检索权重（默认 0.7 向量 + 0.3 关键词）

#### 2. GenerationService（答案生成服务）

```typescript
@Injectable()
export class GenerationService {
  constructor(
    private readonly llm: ChatOpenAI,
    private readonly config: ConfigService,
  ) {}

  // 生成答案
  async generate(query: string, context: RetrievedChunk[]): Promise<GeneratedAnswer>

  // 流式生成
  async generateStream(query: string, context: RetrievedChunk[]): AsyncGenerator<string>
}
```

**Prompt 模板：**
```
你是一个知识库助手。根据以下参考资料回答用户问题。

## 参考资料
{context_chunks}

## 用户问题
{query}

## 要求
1. 基于参考资料回答，不要编造信息
2. 在答案中标注引用来源 [1][2]...
3. 如果参考资料不足以回答，请说明
```

**响应结构：**
```typescript
interface GeneratedAnswer {
  answer: string;           // 生成的答案
  citations: Citation[];    // 引用列表
  confidence: number;       // 置信度（0-1）
}

interface Citation {
  index: number;            // 引用编号
  documentId: string;       // 文档 ID
  documentTitle: string;    // 文档标题
  chunkContent: string;     // chunk 内容
  heading: string;          // 章节标题
  similarity: number;       // 相似度分数
}
```

#### 3. RagService（业务编排）

```typescript
@Injectable()
export class RagService {
  constructor(
    private readonly retrievalService: RetrievalService,
    private readonly generationService: GenerationService,
  ) {}

}
```

#### 4. RagController（API 接口）

```typescript
@Controller('rag')
export class RagController {
  constructor(private readonly ragService: RagService) {}

}
```

## 阶段 2：Agentic 编排

### 目标
增强 RAG 系统的智能能力，包括问题理解、检索策略选择、迭代检索。

### 新增模块

```
src/rag/
├── agent/
│   ├── agent-orchestrator.service.ts   # Agent 编排器
│   ├── question-analyzer.service.ts    # 问题分析/改写
│   ├── strategy-selector.service.ts    # 检索策略选择
│   └── answer-evaluator.service.ts     # 答案质量评估
```

### 核心服务

#### 1. QuestionAnalyzer（问题分析服务）

```typescript
@Injectable()
export class QuestionAnalyzer {
  // 问题改写（优化检索效果）
  async rewrite(question: string): Promise<RewrittenQuery>

  // 意图识别
  async classifyIntent(question: string): QueryIntent

  // 查询扩展（生成多个检索词）
  async expand(question: string): Promise<string[]>
}
```

**意图类型：**
```typescript
enum QueryIntent {
  FACTUAL = 'factual',           // 事实性问题
  PROCEDURAL = 'procedural',     // 流程/操作问题
  COMPARATIVE = 'comparative',   // 比较问题
  EXPLANATORY = 'explanatory',   // 解释性问题
}
```

#### 2. StrategySelector（策略选择服务）

```typescript
@Injectable()
export class StrategySelector {
  // 根据问题类型选择检索策略
  selectStrategy(intent: QueryIntent, question: string): RetrievalStrategy
}

interface RetrievalStrategy {
  searchType: 'vector' | 'keyword' | 'hybrid';
  topK: number;
  rerank: boolean;
  expandQuery: boolean;
}
```

#### 3. AnswerEvaluator（答案评估服务）

```typescript
@Injectable()
export class AnswerEvaluator {
  // 评估答案质量
  async evaluate(answer: GeneratedAnswer, question: string): Promise<EvaluationResult>

  // 判断是否需要追问
  shouldFollowUp(evaluation: EvaluationResult): boolean
}

interface EvaluationResult {
  relevance: number;      // 相关性（0-1）
  completeness: number;   // 完整性（0-1）
  confidence: number;     // 置信度（0-1）
  needsFollowUp: boolean; // 是否需要追问
  followUpQuestion?: string; // 追问建议
}
```

#### 4. AgentOrchestrator（Agent 编排器）

```typescript
@Injectable()
export class AgentOrchestrator {
  constructor(
    private readonly questionAnalyzer: QuestionAnalyzer,
    private readonly strategySelector: StrategySelector,
    private readonly retrievalService: RetrievalService,
    private readonly generationService: GenerationService,
    private readonly answerEvaluator: AnswerEvaluator,
  ) {}

  // Agentic RAG 查询流程
  async query(question: string, options?: AgentOptions): Promise<AgentResponse>
}
```

**Agent 流程：**
```
用户问题
    │
    ▼
┌─────────────────┐
│ 问题分析         │ → 改写、意图识别、查询扩展
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 策略选择         │ → 根据意图选择检索策略
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 第一轮检索       │ → 执行检索
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 答案生成         │ → LLM 生成答案
└─────────────────┘
    │
    ▼
┌─────────────────┐
│ 答案评估         │ → 评估质量，判断是否需要追问
└─────────────────┘
    │
    ├── 满意 → 返回答案
    │
    └── 不满意 → 追问/扩展检索 → 回到第一轮检索
```

## 阶段 3：多轮对话

### 目标
支持多轮对话，维护上下文，实现追问和引导。

### 数据模型

#### PostgreSQL - `kh_conversation` 表

```sql
CREATE TABLE kh_conversation (
  id BIGINT PRIMARY KEY,                    -- 雪花 ID
  user_id BIGINT,                           -- 用户 ID
  title VARCHAR(255),                       -- 对话标题（自动生成）
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  deleted BOOLEAN DEFAULT FALSE
);
```

#### PostgreSQL - `kh_message` 表

```sql
CREATE TABLE kh_message (
  id BIGINT PRIMARY KEY,                    -- 雪花 ID
  conversation_id BIGINT NOT NULL,          -- 对话 ID
  role VARCHAR(20) NOT NULL,                -- user | assistant
  content TEXT NOT NULL,                    -- 消息内容
  citations JSONB,                          -- 引用（仅 assistant）
  query_id VARCHAR(100),                    -- 查询 ID（仅 assistant）
  created_at TIMESTAMP DEFAULT NOW(),
  FOREIGN KEY (conversation_id) REFERENCES kh_conversation(id)
);
```

### 新增服务

```
src/rag/
├── conversation.service.ts      # 对话管理
├── context-manager.service.ts   # 上下文管理
```

#### 1. ConversationService（对话管理）

```typescript
@Injectable()
export class ConversationService {
  constructor(
    @InjectModel(Conversation.name) private conversationModel: Model<Conversation>,
    @InjectModel(Message.name) private messageModel: Model<Message>,
  ) {}

  // 创建对话
  async create(userId?: string): Promise<Conversation>

  // 获取对话列表
  async list(userId?: string, page?: number, pageSize?: number): Promise<ConversationList>

  // 获取对话历史
  async getHistory(conversationId: string, limit?: number): Promise<Message[]>

  // 添加消息
  async addMessage(conversationId: string, role: string, content: string, metadata?: any): Promise<Message>

  // 删除对话
  async delete(conversationId: string): Promise<void>
}
```

#### 2. ContextManager（上下文管理）

```typescript
@Injectable()
export class ContextManager {
  // 构建上下文（包含历史对话）
  async buildContext(conversationId: string, currentQuery: string): Promise<ConversationContext>

  // 生成对话式 prompt
  buildConversationalPrompt(context: ConversationContext): string
}

interface ConversationContext {
  history: Message[];           // 历史消息
  currentQuery: string;         // 当前问题
  summary?: string;             // 对话摘要（长对话时压缩）
}
```

**请求：**
```json

  "conversationId": "conv_abc123",  // 可选，不传则创建新对话
```

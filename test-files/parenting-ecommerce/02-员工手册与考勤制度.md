# 萌宝优选员工手册

## 第一章 入职与离职

### 1.1 入职流程

新员工入职需完成以下步骤：

1. **资料提交**：入职前3个工作日提交身份证、学历证明、离职证明、银行卡信息
2. **合同签署**：入职当日签署劳动合同（首次签订期限为3年，试用期6个月）
3. **系统开通**：IT部门开通企业邮箱、飞书账号、VPN权限
4. **入职培训**：参加为期3天的新员工入职培训（详见《新员工培训手册》）
5. **导师分配**：由直属上级指定一位入职导师，为期1个月

### 1.2 试用期管理

- 试用期为6个月，期间薪资为正式薪资的80%
- 入职满3个月进行中期评估，由直属上级和HR共同完成
- 入职满6个月进行转正评估，评估维度包括：
  - 工作业绩（权重50%）
  - 文化价值观匹配（权重20%）
  - 专业能力成长（权重20%）
  - 团队协作（权重10%）
- 评估总分≥80分予以转正，60-79分延长试用期1-3个月，<60分终止试用

### 1.3 离职流程

- 正式员工需提前30天提交书面离职申请
- 试用期员工需提前3天提交书面离职申请
- 离职交接清单由直属上级和HR共同确认
- 最后一个工作日完成资产归还（电脑、工牌、门禁卡等）
- 离职证明在完成交接后5个工作日内出具

## 第二章 工作时间与考勤

### 2.1 工作时间

- 标准工作时间：周一至周五，9:30-18:30（含1小时午休）
- 弹性上班时间：9:00-10:00到岗，对应18:00-19:00离岗
- 午休时间：12:00-13:00（不计入工作时间）

### 2.2 打卡规定

- 使用飞书打卡，每日上下班各打卡一次
- 忘记打卡需在当日内提交补卡申请，经直属上级审批
- 每月补卡次数不超过3次，超出部分按旷工半天处理
- 外勤打卡需提前在系统中申请外勤审批

### 2.3 加班管理

- 加班需提前在飞书提交加班申请，经直属上级审批
- 工作日加班：按1.5倍工资计算或兑换调休
- 周末加班：按2倍工资计算或兑换调休
- 法定节假日加班：按3倍工资计算，不支持调休兑换
- 每月加班时长上限为36小时（符合劳动法规定）
- 调休有效期为6个月，过期自动清零

### 2.4 请假制度

| 假期类型 | 天数 | 薪资 | 审批流程 |
|----------|------|------|----------|
| 年假 | 5-15天（按工龄） | 全薪 | 直属上级→HR |
| 病假 | 累计不超过医疗期 | 按当地最低工资80% | 直属上级→HR（需提供医院证明） |
| 事假 | 不限 | 无薪 | 直属上级→HR |
| 婚假 | 3天（晚婚+7天） | 全薪 | 直属上级→HR→VP |
| 产假/陪产假 | 按当地政策 | 全薪 | 直属上级→HR→VP |
| 丧假 | 1-3天 | 全薪 | 直属上级→HR |

### 2.5 远程办公政策

- 正式员工入职满6个月后可申请远程办公
- 每周最多2天远程办公，需提前1天在飞书申请
- 远程办公期间需保持飞书在线，响应时间不超过30分钟
- 以下岗位不支持远程办公：客服、仓储、前台
- 远程办公期间不得从事与工作无关的活动

## 第三章 薪酬与福利

### 3.1 薪资结构

```
月薪 = 基本工资（60%）+ 绩效工资（30%）+ 岗位津贴（10%）
```

- 基本工资：每月固定发放
- 绩效工资：根据月度绩效考核结果发放（S:120%、A:110%、B:100%、C:80%、D:0%）
- 岗位津贴：包括交通补贴、通讯补贴、餐补

### 3.2 绩效考核

- 考核周期：月度考核 + 季度考核 + 年度考核
- 考核等级分布：
  - S（卓越）：不超过10%
  - A（优秀）：不超过20%
  - B（良好）：约50%
  - C（待改进）：不超过15%
  - D（不合格）：不超过5%
- 连续2个月D级或年度累计3个月D级，公司有权调岗或解除合同
- 年度考核S级员工优先晋升，A级员工获得年终奖加成

### 3.3 员工福利

- **五险一金**：按当地最高基数缴纳
- **补充医疗保险**：覆盖员工及一名家属（配偶或子女）
- **年度体检**：每年一次全面体检
- **节日福利**：春节、中秋、端午发放节日礼包（价值500-1000元）
- **生日福利**：生日当月发放200元购物卡 + 蛋糕券
- **员工折扣**：平台商品享受员工专属折扣（通常为7-8折）
- **育儿津贴**：家有0-6岁子女的员工，每月额外500元育儿津贴
- **弹性福利积分**：每年3000元弹性福利积分，可用于健身、培训、旅游等

## 第四章 行为规范

### 4.1 职业道德

- 诚实守信，不弄虚作假
- 保守公司商业秘密和用户隐私
- 不接受供应商的不当利益（礼品超过200元需上报）
- 不利用职务之便为个人或亲友谋取不当利益

### 4.2 着装要求

- 日常办公：商务休闲装（禁止拖鞋、背心、短裤）
- 重要会议/客户拜访：正装出席
- 直播出镜：按直播团队统一着装要求

### 4.3 信息安全

- 不得将公司内部文件、数据通过个人设备或社交工具传输
- 不得在公共Wi-Fi环境下处理敏感业务数据
- 离开工位需锁屏（Windows: Win+L / Mac: Ctrl+Command+Q）
- 发现数据泄露或安全事件需立即上报IT安全团队（security@mengbao.com）

# 萌宝优选会员体系与积分规则

## 一、会员等级体系

### 1.1 等级划分

萌宝优选会员体系共分为5个等级：

| 等级 | 名称 | 成长值要求 | 保级条件（年） |
|------|------|-----------|---------------|
| V1 | 萌新会员 | 0-999 | 无 |
| V2 | 银卡会员 | 1,000-4,999 | 年消费≥2000元 |
| V3 | 金卡会员 | 5,000-19,999 | 年消费≥8000元 |
| V4 | 铂金会员 | 20,000-49,999 | 年消费≥20000元 |
| V5 | 钻石会员 | 50,000+ | 年消费≥50000元 |

### 1.2 成长值获取方式

| 获取方式 | 成长值 | 说明 |
|----------|--------|------|
| 消费获取 | 1元=1成长值 | 以实际支付金额计算，不含运费和优惠券抵扣部分 |
| 每日签到 | 5成长值/天 | 连续签到第7天额外奖励20成长值 |
| 发表评价 | 10成长值/条 | 带图评价额外+10，视频评价额外+20 |
| 邀请好友注册 | 100成长值/人 | 被邀请人需完成首单 |
| 参与活动 | 10-500成长值 | 以活动页面说明为准 |

### 1.3 成长值扣减规则

- 每年1月1日扣减上一年度获得成长值的50%（衰减机制）
- 退货订单对应的成长值将被扣减
- 违规行为（如刷单、虚假评价）将扣除全部相关成长值

### 2.2 钻石会员专属权益

钻石会员除享受以上权益外，还可获得：

- **专属育儿顾问**：1对1育儿顾问服务（微信私聊），工作日9:00-21:00在线
- **品牌体验官**：每月可申请2款新品免费试用（需提交试用报告）
- **家庭健康顾问**：每季度1次在线问诊（合作三甲医院儿科医生）
- **亲子活动优先权**：线下亲子活动、品牌见面会优先报名
- **年度消费报告**：年终提供个性化消费分析报告和育儿建议

## 三、积分体系

### 3.1 积分获取规则

| 获取方式 | 积分 | 说明 |
|----------|------|------|
| 消费获取 | 1元=1积分 | 以实际支付金额计算 |
| 每日签到 | 10积分/天 | 连续签到奖励递增 |
| 发表评价 | 20积分/条 | 带图+20，视频+50 |
| 分享商品 | 5积分/次 | 每日上限5次 |
| 参与问卷 | 50-200积分 | 以问卷说明为准 |
| 邀请好友注册 | 200积分/人 | 被邀请人完成首单后发放 |

**连续签到奖励递增规则：**

| 连续天数 | 每日积分 | 额外奖励 |
|----------|----------|----------|
| 1-6天 | 10 | 无 |
| 7天 | 10 | +30（共40） |
| 14天 | 10 | +60（共70） |
| 21天 | 10 | +100（共110） |
| 30天 | 10 | +200（共210） |

### 3.2 积分使用方式

| 使用方式 | 积分价值 | 说明 |
|----------|----------|------|
| 积分抵现 | 100积分=1元 | 下单时勾选积分抵扣，单笔最多抵扣50% |
| 积分兑换优惠券 | 详见积分商城 | 5元券=400积分、10元券=750积分、20元券=1400积分 |
| 积分兑换商品 | 详见积分商城 | 专属积分兑换商品，定期更新 |
| 积分抽奖 | 10积分/次 | 奖品包括优惠券、实物商品、大额红包 |
| 积分换购 | 详见活动页 | 大促期间积分+现金换购专属商品 |

### 3.3 积分有效期

- 积分有效期为获得之日起12个月
- 每月1日自动清零过期积分
- 清零前7天通过App推送和短信提醒用户
- V4及以上等级会员积分有效期延长至24个月

### 3.4 积分退还规则

- 使用积分抵扣的订单退货时，积分将在审核通过后24小时内退回
- 退回的积分保持原有效期不变
- 已过期积分不予退还

## 四、会员活动

### 4.1 会员日

每月18日为萌宝优选会员日：

- **全场双倍积分**：当日消费可获得2倍积分
- **会员专属券**：各等级会员可领取专属满减券
- **积分翻倍签到**：当日签到获得双倍积分
- **秒杀专区**：会员专属秒杀商品（限V2及以上）

### 4.2 会员生日特权

- 生日前7天系统自动发放生日礼包
- 生日当月消费可获得双倍成长值
- 生日当天签到获得10倍积分
- V4及以上会员生日当月可领取品牌联名生日礼盒

### 4.3 年度会员盛典

每年12月举办年度会员盛典：

- 年度消费排行榜（前100名有额外奖励）
- 积分大抽奖（奖品包括iPhone、戴森、全年免费纸尿裤等）
- 会员等级直升活动（消费满额可直升下一等级）
- 老会员回归礼（超过6个月未消费的会员回归首单额外优惠）

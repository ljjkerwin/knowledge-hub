# 萌宝优选客服话术与售后政策

## 一、客服基本规范

### 1.1 服务态度

- **热情友好**：使用亲切自然的语气，称呼用户为"亲"或"宝妈/宝爸"
- **专业耐心**：对育儿相关咨询给予专业、耐心的解答
- **积极主动**：主动询问用户需求，不被动等待
- **换位思考**：理解新手爸妈的焦虑情绪，给予情感支持

### 1.2 响应时效

| 渠道 | 首次响应 | 后续响应 | 服务时间 |
|------|----------|----------|----------|
| 在线客服 | ≤30秒 | ≤60秒 | 8:00-24:00 |
| 电话客服 | ≤20秒接通 | - | 9:00-21:00 |
| 社群客服 | ≤5分钟 | ≤10分钟 | 8:00-22:00 |
| 邮件/工单 | ≤2小时 | ≤4小时 | 工作日9:00-18:30 |

### 1.3 禁用语

以下表达方式在客服沟通中严格禁止：

- "这不是我们的问题"
- "你自己看详情页"
- "我们也没办法"
- "其他平台也这样"
- "你去投诉吧"
- "不可能有这种情况"
- "你是不是搞错了"

## 二、常见场景话术

### 2.1 售前咨询

**场景1：用户询问商品是否适合自家宝宝年龄**

> 亲，这款产品适合6-36个月的宝宝使用哦~ 您家宝宝多大了呢？我帮您看看是否合适，也可以根据宝宝的具体情况给您推荐更匹配的款式呢 😊

**场景2：用户对比其他平台价格**

> 亲，您对比得很仔细呢！我们的定价已经是非常有竞争力的了，而且我们还有几个优势：1）所有商品都是品牌直供，100%正品保证；2）购买后有专属育儿顾问提供使用指导；3）7天无理由退换，售后无忧~ 如果您加入我们的会员，还能享受额外折扣哦！

**场景3：用户询问商品安全性**

> 亲，这款产品通过了国家3C认证/SGS检测，我给您看一下检测报告的照片~（发送检测报告图片）。我们平台上架的所有母婴产品都经过严格的品控审核，安全性是我们最看重的。如果您还有任何疑虑，随时问我哦！

**场景4：用户询问发货时间**

> 亲，下单后我们会在48小时内安排发货，默认使用顺丰/京东物流。一般江浙沪1-2天到达，其他地区2-4天。如果遇到大促活动，发货时间可能会延长1-2天，我们会提前在商品页面说明的~

### 2.2 售后处理

**场景5：用户反馈收到商品有质量问题**

> 亲，非常抱歉给您带来了不好的体验！请您先拍几张照片/视频给我看一下具体情况，我马上为您处理。您可以选择：1）退货退款，运费由我们承担；2）换货，我们会优先为您安排发出新品。真的很抱歉让您遇到这种情况，我们会加强品控的 🙏

**场景6：用户申请退货（非质量问题）**

> 亲，收到您的退货申请了。我们支持7天无理由退换哦，请您保持商品完好、包装完整，在订单页面申请退货即可。审核通过后会提供退货地址和运单号。退回商品验收无误后，退款会在1-3个工作日内原路返回您的账户~

**场景7：用户反馈物流信息不更新**

> 亲，我帮您查一下物流信息~（查询后）目前显示包裹在XX中转站，可能是物流高峰期有延迟。我这边已经帮您催促快递公司了，如果24小时后还没有更新，我们会为您安排补发或退款，您看可以吗？

**场景8：用户对商品不满意想差评**

> 亲，很抱歉我们的商品没有达到您的期望 😔 方便告诉我具体是哪里不满意吗？我们非常重视您的反馈。如果是产品本身的问题，我们可以为您办理退货退款；如果是使用上的疑问，我们的育儿顾问可以给您提供专业的使用建议。希望能给您一个满意的解决方案~

### 2.3 育儿咨询

**场景9：用户询问奶粉选择**

> 亲，选择奶粉确实很重要呢！一般来说，我们会从以下几个维度考虑：
> 1. **宝宝月龄**：0-6个月选1段，6-12个月选2段，12-36个月选3段
> 2. **体质特点**：如果宝宝有乳糖不耐受或过敏情况，需要选择特殊配方
> 3. **营养需求**：关注DHA、ARA、益生元等关键成分
>
> 您家宝宝多大了？有没有特殊的体质情况？我帮您推荐几款适合的~

**场景10：用户询问辅食添加**

> 亲，宝宝辅食添加一般从6个月开始，遵循"由少到多、由稀到稠、由细到粗、由一种到多种"的原则。初期可以从含铁米粉开始，逐渐添加蔬菜泥、水果泥、肉泥等。我们平台有详细的辅食添加时间表，我发给您参考一下~ 不过每个宝宝发育节奏不同，建议以儿保医生的建议为准哦！

## 三、售后政策

### 3.1 退换货政策

| 情况 | 时效 | 运费承担 | 退款方式 |
|------|------|----------|----------|
| 7天无理由退货 | 收货后7天内 | 买家承担 | 原路退款 |
| 质量问题退货 | 收货后15天内 | 卖家承担 | 原路退款 |
| 发错货/漏发 | 收货后7天内 | 卖家承担 | 原路退款或补发 |
| 运输破损 | 收货后48小时内 | 卖家承担 | 原路退款或补发 |
| 过敏退货（食品/护肤） | 收货后30天内 | 卖家承担 | 原路退款（需提供医院证明） |

### 3.2 退款时效

- 审核通过后，退款将在1-3个工作日内原路返回
- 微信支付退款到账时间：1-3个工作日
- 支付宝退款到账时间：1-2个工作日
- 银行卡退款到账时间：3-7个工作日（取决于银行处理速度）

### 3.3 赔偿标准

| 问题类型 | 赔偿方式 |
|----------|----------|
| 发错货 | 补发正确商品 + 赠送20元优惠券 |
| 漏发 | 补发漏发商品 + 赠送10元优惠券 |
| 运输破损 | 退款或补发 + 赠送15元优惠券 |
| 质量问题 | 退款 + 赠送30元优惠券 + 品控反馈 |
| 延迟发货（超48小时） | 赠送5元优惠券/积分补偿 |

### 3.4 特殊品类售后规则

**奶粉/食品类：**
- 已开封的食品不支持7天无理由退货
- 如有质量问题（结块、异物、异味），需提供照片/视频证据
- 因宝宝过敏退货，需提供医院过敏原检测报告

**纸尿裤/湿巾类：**
- 未拆封可享受7天无理由退货
- 已拆封但未使用的，如存在质量问题可退换
- 已使用过的不支持退换（质量问题除外，需提供实物照片）

**童装/童鞋类：**
- 未穿着、未洗涤、吊牌完整可享受7天无理由退货
- 童鞋需保持鞋底干净，无明显穿着痕迹
- 尺码不合可免费换码一次（限同款同色）

## 四、升级处理机制

### 4.1 客诉升级流程

```
一线客服（L1）→ 高级客服（L2）→ 客服主管（L3）→ 客服经理（L4）→ VP/CEO（L5）
```

| 级别 | 处理权限 | 触发条件 |
|------|----------|----------|
| L1 | 话术安抚、常规退换货 | 首次接触 |
| L2 | 额外补偿（≤50元优惠券） | 用户不满意L1处理结果 |
| L3 | 额外补偿（≤200元）+ 专人跟进 | 用户要求主管处理或投诉到社交媒体 |
| L4 | 额外补偿（≤500元）+ 高管道歉 | 用户投诉到监管部门或媒体曝光 |
| L5 | 无上限补偿决策 | 重大舆情事件或法律纠纷 |

### 4.2 升级话术

> 亲，非常理解您的心情，这个问题我马上为您升级到主管处理。我们的主管XX会在30分钟内联系您，给您一个满意的解决方案。在此期间，如果您有任何补充信息，也可以随时告诉我~

# 萌宝优选商品选品与品控标准

## 一、选品原则

### 1.1 核心选品理念

萌宝优选的选品遵循"三高一严"原则：

- **高品质**：产品必须通过国家相关质量认证，优先选择行业头部品牌
- **高性价比**：同等品质下价格优于或持平主流电商平台
- **高复购**：优先选择消耗品、高频使用品类
- **严标准**：所有商品必须通过萌宝优选品控团队的评审

### 1.2 品类覆盖范围

| 一级品类 | 二级品类举例 | 选品优先级 |
|----------|-------------|-----------|
| 奶粉辅食 | 婴幼儿奶粉、米粉、果泥、零食 | ★★★★★ |
| 纸尿裤洗护 | 纸尿裤、湿巾、婴儿沐浴露、面霜 | ★★★★★ |
| 童装童鞋 | 内衣、外套、学步鞋、运动鞋 | ★★★★ |
| 玩具益智 | 积木、拼图、早教机、绘本 | ★★★★ |
| 孕产用品 | 待产包、孕妇装、产后恢复 | ★★★ |
| 儿童家居 | 婴儿床、安全座椅、餐椅 | ★★★ |
| 儿童营养 | 维生素D、钙铁锌、DHA | ★★★ |
| 文具学习 | 书包、文具、学习桌 | ★★ |

### 1.3 禁止选品清单

以下品类或产品禁止上架：

- 无国家强制性认证（3C、食品经营许可证等）的产品
- 含有已被禁用成分的儿童用品（如含硼砂的水晶泥）
- 来源不明的海淘代购商品
- 声称有治疗功效的普通食品或用品
- 二手商品或临期商品（保质期剩余不足2/3的食品）
- 含有暴力、恐怖元素的儿童玩具

## 二、选品流程

### 2.1 选品评审流程

```
品牌方提交资料 → 初审（选品专员）→ 样品评审（品控团队）→ 试用评审（育儿顾问）→ 终审（商品总监）→ 合同签署 → 上架
```

**各环节时限要求：**

| 环节 | 负责人 | 时限 | 输出物 |
|------|--------|------|--------|
| 初审 | 选品专员 | 2个工作日 | 初审报告（资质合规性、品牌背景调研） |
| 样品评审 | 品控团队 | 5个工作日 | 样品检测报告（安全性、功能、外观） |
| 试用评审 | 育儿顾问 | 7个工作日 | 试用体验报告（使用感受、宝宝反馈） |
| 终审 | 商品总监 | 2个工作日 | 终审意见（定价、上架策略） |

### 2.2 品牌方需提交的资料

1. 营业执照副本（加盖公章）
2. 品牌商标注册证或品牌授权书
3. 产品检测报告（CMA/CNAS认可的检测机构出具）
4. 食品类需提供食品经营许可证、食品生产许可证
5. 化妆品类需提供化妆品生产许可证、特殊化妆品注册证
6. 进口商品需提供报关单、入境检验检疫证明
7. 产品实物样品至少2件（含完整包装）

### 2.3 选品评分标准

选品评审采用百分制评分：

| 评分维度 | 权重 | 评分标准 |
|----------|------|----------|
| 安全性 | 30% | 材质安全、无有害物质、符合国标 |
| 品质 | 25% | 做工精细度、耐用性、使用体验 |
| 品牌力 | 15% | 品牌知名度、口碑、市场表现 |
| 性价比 | 15% | 同品质价格优势、利润空间 |
| 育儿价值 | 10% | 对儿童成长的促进作用 |
| 包装设计 | 5% | 包装美观度、环保性、适合送礼 |

- **85分以上**：优先上架，争取首发/独家合作
- **70-84分**：正常上架
- **60-69分**：有条件上架（需品牌方改进后复审）
- **60分以下**：不予上架

## 三、品控标准

### 3.1 入库质检

每批商品入库前需进行抽检：

| 品类 | 抽检比例 | 检测项目 |
|------|----------|----------|
| 奶粉辅食 | 100%全检 | 生产日期、保质期、包装完整性、条码验证 |
| 纸尿裤洗护 | 10%抽样 | 外观、气味、重量、包装密封性 |
| 童装童鞋 | 5%抽样 | 面料手感、做工、尺码标注、甲醛检测 |
| 玩具益智 | 5%抽样 | 小零件牢固度、锐边检查、3C标志验证 |

### 3.2 在库商品管理

- **温湿度监控**：奶粉辅食仓库温度控制在25°C以下，湿度60%以下
- **先进先出**：严格执行FIFO（先进先出）原则，避免商品过期
- **定期巡检**：每周对在库商品进行一次巡检，检查包装完整性
- **效期管理**：保质期剩余不足1/3的食品类商品，自动触发清仓流程

### 3.3 售后品控

- 收到用户品控投诉后，24小时内响应
- 同一批次商品收到3起以上同类投诉，立即启动该批次全检
- 确认存在质量问题的，立即下架该批次商品，并通知已购买用户
- 建立供应商品控档案，累计3次品控问题的供应商终止合作

## 四、供应商管理

### 4.1 供应商分级

| 等级 | 标准 | 权益 |
|------|------|------|
| S级（战略合作） | 年供货额>500万，品控合格率>99% | 优先结算、联合营销、新品首发 |
| A级（优质合作） | 年供货额>100万，品控合格率>97% | 正常结算、活动优先参与 |
| B级（一般合作） | 年供货额>30万，品控合格率>95% | 正常结算 |
| C级（观察合作） | 未达B级标准 | 延长账期、限制上新 |

### 4.2 供应商考核

每季度对供应商进行考核，考核指标包括：

- **供货及时率**（权重25%）：订单确认后48小时内发货比例
- **品控合格率**（权重30%）：入库质检通过率
- **售后配合度**（权重20%）：退换货响应速度和配合程度
- **价格竞争力**（权重15%）：同类产品价格对比
- **创新合作**（权重10%）：新品推荐、独家定制配合度

连续两个季度考核为C级的供应商，启动淘汰流程。

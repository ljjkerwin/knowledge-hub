# 萌宝优选公司介绍与企业文化

## 公司简介

萌宝优选（MengBao Select）成立于2021年，是一家专注于亲子育儿赛道的社交电商平台。公司总部位于杭州，在上海、广州、成都设有分公司，员工总数超过500人。

公司致力于为0-12岁儿童家庭提供高品质、高性价比的母婴产品和育儿服务，通过"内容+社群+电商"的创新模式，帮助千万宝妈宝爸轻松育儿、智慧消费。

### 企业愿景

成为中国最受信赖的亲子家庭消费平台，让每个孩子都能享受到优质的成长陪伴。

### 企业使命

用专业和温度连接优质品牌与年轻家庭，让育儿更简单、更快乐。

### 核心价值观

| 价值观 | 含义 | 行为准则 |
|--------|------|----------|
| 用户第一 | 一切决策以用户体验为中心 | 每个产品上架前必须经过育儿顾问团队试用评审 |
| 专业可信 | 以科学育儿知识建立信任 | 所有育儿内容需经儿科医生或营养师审核 |
| 真诚分享 | 真实体验是最好的推荐 | 禁止虚假种草，鼓励真实使用反馈 |
| 共同成长 | 与用户、品牌、员工一起成长 | 每季度举办品牌共创会和用户开放日 |

## 组织架构

```
CEO
├── 运营中心（运营VP）
│   ├── 内容运营部（15人）——负责育儿知识内容生产与分发
│   ├── 社群运营部（20人）——管理妈妈社群和KOC培育
│   ├── 用户运营部（12人）——用户增长、留存、会员体系
│   └── 活动运营部（8人）——大促活动策划与执行
├── 商品中心（商品VP）
│   ├── 选品部（10人）——产品调研、供应商洽谈、选品评审
│   ├── 品控部（8人）——产品质量检测与标准制定
│   └── 供应链部（15人）——仓储物流、库存管理
├── 技术中心（CTO）
│   ├── 产品部（6人）——产品规划与需求管理
│   ├── 前端开发部（8人）——App和小程序开发
│   ├── 后端开发部（12人）——服务端、中间件、数据
│   └── AI与数据部（6人）——推荐系统、知识库、数据分析
├── 销售中心（销售VP）
│   ├── 品牌合作部（10人）——品牌招商与商务合作
│   └── KOC管理部（15人）——达人孵化与分销管理
└── 职能中心
    ├── 人力资源部（6人）
    ├── 财务部（5人）
    ├── 法务合规部（4人）
    └── 行政部（4人）
```

## 公司发展历程

| 时间 | 里程碑 |
|------|--------|
| 2021年3月 | 公司成立，获得天使轮融资2000万元 |
| 2021年9月 | 小程序上线，首月GMV突破500万 |
| 2022年4月 | 完成A轮融资1.5亿元，用户突破100万 |
| 2022年11月 | 首届"萌宝好物节"，单日GMV破3000万 |
| 2023年6月 | 推出自有品牌"萌宝严选"系列 |
| 2023年12月 | 年度GMV突破20亿，KOC数量达5万人 |
| 2024年5月 | AI智能育儿助手上线，知识库系统建成 |
| 2024年12月 | 年度GMV突破50亿，注册用户超2000万 |
| 2025年8月 | 完成C轮融资5亿元，估值超60亿 |

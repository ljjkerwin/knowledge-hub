# 萌宝优选物流与仓储管理制度

## 一、仓储管理

### 1.1 仓库布局

萌宝优选在全国设有3个自营仓库：

| 仓库 | 位置 | 面积 | 覆盖区域 | 日均发货能力 |
|------|------|------|----------|-------------|
| 华东仓 | 杭州 | 5000㎡ | 浙江、江苏、上海、安徽、江西 | 8000单 |
| 华南仓 | 广州 | 3000㎡ | 广东、福建、广西、海南、湖南 | 5000单 |
| 华北仓 | 武汉 | 3000㎡ | 湖北、河南、四川、重庆、陕西 | 5000单 |

**仓库功能分区：**
- 收货区（占比10%）：来货验收、质检
- 存储区（占比50%）：按品类分区存放
- 拣货区（占比20%）：高频商品前置
- 打包区（占比10%）：打包、贴单
- 发货区（占比10%）：集货、交接给物流公司

### 1.2 库存管理原则

**安全库存公式：**
```
安全库存 = 日均销量 × 补货周期（天）× 1.5
```

**库存周转率目标：**
| 品类 | 目标周转天数 | 预警线 |
|------|-------------|--------|
| 奶粉辅食 | 30天 | 超过45天预警 |
| 纸尿裤洗护 | 25天 | 超过40天预警 |
| 童装童鞋 | 60天 | 超过90天预警 |
| 玩具益智 | 45天 | 超过60天预警 |

**先进先出（FIFO）执行标准：**
- 所有商品必须按照入库时间顺序出库
- 同一SKU不同批次的商品，系统自动分配最早批次出库
- 每月盘点时检查临期商品（保质期剩余不足1/3的食品）
- 临期商品转入促销区或联系供应商退换

### 1.3 仓库温湿度管理

| 区域 | 温度要求 | 湿度要求 | 存放商品 |
|------|----------|----------|----------|
| 常温区 | 15-30°C | ≤70% | 玩具、文具、童装 |
| 阴凉区 | ≤25°C | ≤65% | 奶粉、辅食、营养品 |
| 冷藏区 | 2-8°C | - | 部分益生菌、特殊食品 |
| 高值区 | 常温 | ≤60% | 高价商品（安全座椅等） |

温湿度监控系统24小时运行，每30分钟自动记录一次数据。超出预警范围时，系统自动发送告警通知至仓库管理员。

## 二、入库流程

### 2.1 来货预约

- 供应商需提前48小时在供应商系统提交送货预约
- 预约内容包括：送货时间、车辆信息、SKU清单、预计数量
- 仓库根据预约安排收货人员和库位
- 未预约的来货原则上不予接收

### 2.2 收货验收流程

```
车辆到达 → 卸货 → 外观检查 → 数量清点 → 质量抽检 → 系统录入 → 上架
```

**外观检查标准：**
- 外包装无破损、变形、受潮
- 标签清晰完整（品名、规格、生产日期、保质期）
- 数量与送货单一致（允许±2%误差）

**质量抽检标准：**

| 品类 | 抽检比例 | 检查项目 |
|------|----------|----------|
| 奶粉辅食 | 100%全检 | 生产日期、保质期、包装密封性、条码 |
| 纸尿裤洗护 | 10% | 外观、重量、密封性 |
| 童装童鞋 | 5% | 面料、做工、尺码标识 |
| 玩具益智 | 5% | 外观、小零件牢固度、3C标识 |

### 2.3 上架规则

- 系统根据商品属性自动分配库位
- 同一SKU集中存放，便于拣货
- 高频出库商品放置在靠近拣货区的库位
- 重的商品放下层，轻的放上层
- 每个库位有唯一编码，系统实时更新库存位置

## 三、出库流程

### 3.1 订单处理流程

```
订单生成 → 库存锁定 → 拣货 → 复核 → 打包 → 贴单 → 发货
```

**时效要求：**
- 普通订单：下单后48小时内发货
- 加急订单：下单后24小时内发货
- 预售订单：按商品页面标注的时间发货

### 3.2 拣货方式

采用**波次拣货**方式：
1. 系统每30分钟生成一个拣货波次
2. 同一波次的订单按库位路径优化排序
3. 拣货员使用PDA扫描商品条码确认
4. 拣货完成后送至复核区

### 3.3 复核标准

- 核对商品SKU、数量与订单一致
- 检查商品外观完好、保质期合格
- 扫描商品条码与订单绑定
- 复核通过后进入打包环节
- 复核不通过的退回拣货区重新处理

### 3.4 打包标准

| 商品类型 | 包装方式 | 填充物 |
|----------|----------|--------|
| 奶粉/食品 | 纸箱+气泡膜 | 气柱袋 |
| 纸尿裤 | 快递袋或纸箱 | 无需填充 |
| 童装 | 快递袋 | 无需填充 |
| 玩具 | 纸箱+气泡膜 | 珍珠棉 |
| 易碎品 | 纸箱+双层气泡膜 | 气柱袋+珍珠棉 |

**包装要求：**
- 外包装不得出现商品价格信息
- 随包裹放入发货清单、售后卡
- 大促期间可放入品牌宣传物料
- 包裹封口牢固，胶带粘贴整齐

## 四、物流合作

### 4.1 合作物流公司

| 物流公司 | 合作类型 | 覆盖范围 | 价格区间 |
|----------|----------|----------|----------|
| 顺丰速运 | 主力合作 | 全国 | 8-15元/单 |
| 京东物流 | 主力合作 | 全国 | 6-12元/单 |
| 中通快递 | 补充合作 | 全国 | 3-6元/单 |
| 韵达快递 | 补充合作 | 全国 | 3-6元/单 |
| 顺丰冷链 | 专项合作 | 冷链覆盖区域 | 15-25元/单 |

**物流分配规则：**
- 默认使用顺丰或京东物流（品质保障）
- 用户可选择普通快递（优惠3-5元运费）
- 冷链商品（如部分益生菌）使用顺丰冷链
- 偏远地区（新疆、西藏、青海）使用顺丰

### 4.2 物流时效承诺

| 区域 | 标准时效 | 加急时效 |
|------|----------|----------|
| 江浙沪 | 1-2天 | 次日达 |
| 华东/华南 | 2-3天 | 2天达 |
| 华中/华北 | 3-4天 | 3天达 |
| 西南/西北 | 4-5天 | 3天达 |
| 偏远地区 | 5-7天 | 5天达 |

### 4.3 物流异常处理

| 异常类型 | 处理方式 | 时限 |
|----------|----------|------|
| 物流信息48小时未更新 | 联系快递公司催件 | 24小时内 |
| 包裹丢失 | 补发或退款 | 48小时内 |
| 包裹破损 | 拍照取证→补发或退款 | 24小时内 |
| 派送超时 | 联系快递公司催派 | 12小时内 |
| 错发/漏发 | 确认后立即补发 | 24小时内 |

## 五、退换货物流

### 5.1 退货物流规则

- 7天无理由退货：买家承担退回运费
- 质量问题退货：卖家承担运费（提供到付面单）
- 退货地址：系统自动分配最近仓库
- 退货商品需保持原包装完好

### 5.2 退货入库流程

```
退货到达 → 验收检查 → 判定处理方式 → 系统确认 → 退款/换货
```

**验收检查标准：**
- 包装完好、商品未使用：正常入库，可二次销售
- 包装轻微损坏、商品完好：转为瑕疵品处理（折扣销售）
- 商品已使用或损坏：报废处理

### 5.3 退款时效

- 退货入库验收通过后，1-3个工作日完成退款
- 退款原路返回（微信/支付宝/银行卡）
- 银行卡退款到账时间3-7个工作日

# 育儿知识库：新生儿护理指南（0-3个月）

## 一、喂养指导

### 1.1 母乳喂养

**喂养频率：**
- 新生儿期（0-28天）：每天8-12次，每次15-20分钟
- 按需喂养为主，不必严格按时间间隔
- 观察饥饿信号：吮吸动作、转头寻乳、把手放嘴边

**正确衔乳姿势：**
1. 宝宝身体侧向妈妈，肚子贴肚子
2. 宝宝嘴巴张大（像打哈欠一样）
3. 含住大部分乳晕，而非仅含乳头
4. 吸吮时有节奏的吞咽声
5. 妈妈无明显疼痛感

**判断奶量是否充足：**
- 出生后前3天：每天至少1-2片湿尿布
- 出生后4-6天：每天至少6片湿尿布
- 大便从墨绿色胎便逐渐转为黄色糊状
- 体重变化：出生后3-5天内体重下降不超过7%，之后开始回升
- 满月时体重增长600g以上

### 1.2 配方奶喂养

**冲调方法：**
1. 洗手并消毒奶瓶、奶嘴
2. 将水烧开后冷却至40-50°C（具体温度参照奶粉说明）
3. 先加水，再加奶粉（严格按照说明书比例）
4. 轻轻摇匀，避免剧烈摇晃产生气泡
5. 手腕内侧试温（感觉温热不烫为宜）
6. 冲调后2小时内饮用完毕，剩余奶液倒掉

**喂奶量参考（仅供参考，以宝宝实际需求为准）：**

| 日龄 | 每次奶量 | 每日次数 | 每日总量 |
|------|----------|----------|----------|
| 1-3天 | 5-15ml | 8-12次 | 40-180ml |
| 4-7天 | 30-60ml | 8-10次 | 240-600ml |
| 1-2周 | 60-90ml | 7-8次 | 420-720ml |
| 2-4周 | 90-120ml | 6-8次 | 540-960ml |

### 1.3 拍嗝方法

每次喂奶后需拍嗝，防止溢奶和胀气：

1. **肩上拍嗝法**：将宝宝竖抱，头靠在肩膀上，空心掌轻拍背部
2. **坐姿拍嗝法**：让宝宝坐在腿上，一手托住下巴和胸部，另一手轻拍背部
3. **俯卧拍嗝法**：让宝宝趴在腿上，头部略高于胸部，轻拍背部

每次拍嗝3-5分钟，如无嗝出，可让宝宝保持右侧卧位15分钟。

## 二、睡眠管理

### 2.1 新生儿睡眠特点

- 每天睡眠时间：16-20小时
- 每次睡眠周期：2-4小时
- 新生儿尚未建立昼夜节律，夜间频繁醒来是正常的
- 约6-8周开始逐渐区分白天和黑夜

### 2.2 安全睡眠指南

**ABC原则：**
- **A（Alone）**：独自睡，不与成人同床
- **B（Back）**：仰卧睡，不要趴睡或侧睡
- **C（Crib）**：睡在婴儿床上，不要睡在沙发、摇椅等软性表面

**婴儿床安全标准：**
- 床垫坚实平整，与床框紧密贴合（缝隙不超过两指宽）
- 不放置枕头、被子、毛绒玩具等松软物品
- 床围不建议使用（有窒息风险）
- 室温保持在22-26°C，宝宝穿着适当厚度的睡袋

### 2.3 哄睡技巧

1. **建立睡前仪式**：洗澡→抚触→换睡衣→喂奶→放床
2. **白噪音**：模拟子宫内的声音环境，帮助宝宝入睡
3. **襁褓包裹**：适度包裹可以减少惊跳反射，增加安全感
4. **抓住睡眠窗口**：观察揉眼睛、打哈欠等疲倦信号，及时哄睡
5. **放下时机**：宝宝入睡后15-20分钟（进入深睡眠）再放下

## 三、日常护理

### 3.1 脐带护理

- 保持脐带残端干燥清洁
- 每天用75%酒精或碘伏消毒脐带根部1-2次
- 尿布不要覆盖脐带，避免摩擦和污染
- 脐带一般在出生后7-14天自然脱落
- 脱落后继续消毒2-3天，直到完全愈合

**异常情况需就医：**
- 脐周皮肤红肿、发热
- 脐部有脓性分泌物或异味
- 脐带残端出血不止
- 超过3周仍未脱落

### 3.2 洗澡指导

**频率：** 新生儿每周洗澡2-3次即可，不必每天洗

**水温：** 37-38°C（用手肘或温度计测试）

**步骤：**
1. 准备好所有用品（毛巾、浴盆、沐浴露、干净衣物、尿布）
2. 先洗脸（用湿毛巾轻轻擦拭）
3. 再洗头（少量婴儿洗发露，指腹轻揉）
4. 最后洗身体（重点清洁颈部、腋下、腹股沟等褶皱处）
5. 用清水冲净，大浴巾包裹，轻轻拍干
6. 抹润肤露，穿好衣物

**注意事项：**
- 洗澡时间控制在5-10分钟
- 全程不要离开宝宝，一只手始终扶住宝宝
- 脐带未脱落前建议擦浴或使用脐带防水贴
- 沐浴露每周使用1-2次即可，过度使用会破坏皮肤屏障

### 3.3 臀部护理

- 每2-3小时更换一次尿布，大便后立即更换
- 更换尿布时用温水清洗臀部，轻轻拍干
- 涂抹护臀膏预防红屁屁（含氧化锌成分的效果较好）
- 条件允许时，每天让宝宝臀部暴露在空气中15-20分钟

**红屁屁处理：**
- 轻度（皮肤微红）：勤换尿布 + 护臀膏，2-3天可好转
- 中度（皮肤红肿、有小疹子）：使用含氧化锌的护臀膏，避免使用湿巾
- 重度（皮肤破溃、渗液）：及时就医，遵医嘱用药

### 3.4 指甲护理

- 使用婴儿专用指甲剪或指甲锉
- 最佳时机：宝宝熟睡时
- 沿着指甲弧度剪，不要剪得太短
- 如不慎剪伤，用干净纱布按压止血，涂抹碘伏消毒
- 每周修剪1-2次

## 四、常见问题处理

### 4.1 黄疸

**生理性黄疸：**
- 出生后2-3天出现，4-5天达到高峰，7-10天消退
- 仅面部和躯干发黄，宝宝精神状态好，吃奶正常
- 多喂奶、多排便有助于黄疸消退

**需就医的情况：**
- 出生后24小时内出现黄疸
- 黄疸持续超过2周不消退
- 黄疸蔓延到四肢和手心脚心
- 宝宝精神萎靡、拒奶、大便颜色发白

### 4.2 肠绞痛

**典型表现：**
- 多发生在傍晚或夜间
- 突然大声哭闹，难以安抚
- 双腿蜷缩、腹部胀硬
- 每次持续数十分钟到数小时
- 多见于2-4周龄，3-4个月后逐渐好转

**缓解方法：**
1. 飞机抱：让宝宝趴在手臂上，轻轻摇晃
2. 顺时针按摩腹部：促进肠道排气
3. 温毛巾敷腹部：注意温度不要过高
4. 白噪音安抚
5. 母乳妈妈减少易产气食物（豆类、花椰菜、洋葱等）
6. 喂奶后充分拍嗝

### 4.3 吐奶

- 新生儿吐奶多数是正常的生理现象（胃呈水平位、贲门松弛）
- 喂奶后保持竖抱15-20分钟
- 避免喂奶后立即剧烈活动或换尿布
- 少量多次喂奶，避免过度喂养

**需警惕的吐奶：**
- 喷射性呕吐（奶液喷出很远）
- 呕吐物带血或呈绿色
- 体重不增长或下降
- 伴随发热、腹泻等症状

以上情况需立即就医。

## 五、疫苗接种

### 5.1 出生后即接种

| 疫苗 | 接种时间 | 接种部位 |
|------|----------|----------|
| 乙肝疫苗（第1针） | 出生后24小时内 | 大腿前外侧 |
| 卡介苗 | 出生后24小时内 | 左上臂三角肌 |

### 5.2 满月后接种

| 疫苗 | 接种时间 |
|------|----------|
| 乙肝疫苗（第2针） | 1月龄 |
| 脊灰疫苗（第1剂） | 2月龄 |

**注意事项：**
- 接种前确保宝宝身体健康，无发热、腹泻等症状
- 接种后在医院观察30分钟，无异常后再离开
- 接种部位可能出现红肿、硬结，一般2-3天自行消退
- 如出现高热（>38.5°C）、持续哭闹、皮疹等异常反应，及时就医
